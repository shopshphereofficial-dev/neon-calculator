# Neon Calculator

A colorful, kids-friendly calculator app for Android with glowing neon buttons.

## Features
- Phone-style calculator: +, -, x, /, %, backspace, clear
- Glowing neon design (pink, cyan, purple, lime) on a dark gradient
- Big, chunky buttons - easy for kids to tap
- Expression preview line above the result

## Download
Grab the APK from the [Releases](https://github.com/shopshphereofficial-dev/neon-calculator/releases) page
and install it on any Android 8.0+ phone (enable "Install unknown apps" if asked).

## Build
The APK is built automatically by GitHub Actions on every push - see
`.github/workflows/build.yml`. To build locally: open in Android Studio or run
`gradle assembleDebug`.
